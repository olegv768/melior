# Melior

AI-сервис для малого и среднего бизнеса: находит скрытые потери, узкие места и лишние расходы и предлагает план оптимизации на 30 дней.

Проект для хакатона Zhambyl Hub · трек «AI for SME & Local Business».

## Что внутри

- **Первый экран** — интерактивная 3D-модель бизнес-системы (Three.js / React Three Fiber): ядро анализа и модули «Финансы», «Продажи», «Сотрудники», «Склад», «Автоматизация».
- **Интерактивная аналитика** — дашборд на демо-данных и сценарий «закупки против фактического спроса».
- **AI Business Audit** — анкета → этапы анализа → отчёт: проблемные места, процессы, экономия, автоматизации, план на 30 дней.
- Возможности, «Как это работает», «До и после», отрасли, пример отчёта, FAQ.

Все цифры на сайте — демонстрационные и помечены как примерные.

## ИИ (Gemini)

Отчёт аудита генерирует Gemini через серверную функцию `api/audit.ts`. Ключ хранится **только на сервере** в переменной окружения и никогда не попадает в браузер.

Если ключ не задан, сайт работает в **демонстрационном режиме**: отчёт собирается из заранее подготовленных сценариев, и интерфейс прямо об этом сообщает.

| Переменная | Обязательна | Описание |
|---|---|---|
| `GEMINI_API_KEY` | да, для ИИ-режима | ключ из Google AI Studio |
| `GEMINI_MODEL` | нет | модель, по умолчанию `gemini-2.5-flash` |

## Запуск локально

```bash
npm install
cp .env.example .env.local   # впишите GEMINI_API_KEY
npm run dev
```

`npm run dev` поднимает и сайт, и `/api/audit` (через плагин в `vite.config.ts`), отдельный Vercel CLI не нужен.

## Деплой на Vercel

1. Импортируйте репозиторий на vercel.com → Framework: **Vite** (определится сам).
2. Settings → Environment Variables → добавьте `GEMINI_API_KEY`.
3. Deploy. Функция `api/audit.ts` развернётся автоматически.

## Стек

React 19, Vite, TypeScript, Three.js + React Three Fiber, Framer Motion, Vercel Functions, Gemini API.

## Структура

```
api/audit.ts           серверная функция: проверка анкеты, запрос к Gemini, нормализация ответа
shared/audit.ts        общие типы, валидация, промпт и JSON-схема ответа
src/components/        секции сайта (hero/ — 3D-сцена)
src/lib/demoReport.ts  сценарии демонстрационного режима
src/lib/auditClient.ts клиент аудита и обработка ошибок
```
